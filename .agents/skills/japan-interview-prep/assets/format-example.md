# 面接準備 Markdown 格式示例

生成面接准备内容时照这个格式写，`build_interview_html.py` 就能一键转成带注音的 HTML。
下面每种元素左边是写法、右边是效果。

## ⭐ 速查（本番前に見る）

- **会社**：○○株式会社（設立/人数/年収レンジ…）
- **面接官**：△△様（決裁者）・□□様（技術把関）
- **⭐定位**：「AIを学びに来た人」ではなく「即戦力」

> ⚠️ 金框放最重要的提醒——年収口径、雷区、绝不能忘的一句。

## 想定問答

#### Q1. 志望動機（这是紫色的 Q 小标题）

【面接官】改（あらた）めて、志望（しぼう）理由（りゆう）をお聞（き）かせください。

【あなた】はい。理由（りゆう）は二（ふた）つあります。一（ひと）つ目（め）は…（全部日语话术，难读词写成 漢字（かな），脚本自动转头顶注音）。

▷ 中文策略：这里写"为什么这么答、注意什么、什么场景用"。候选人母语理解最快。⚠️ 用「」不用英文引号，避免脚本处理时的引号冲突。

#### Q2. 希望年収

【あなた】前職（ぜんしょく）では一千万円（いっせんまん）規模（きぼ）でした。御社（おんしゃ）の想定（そうてい）レンジ内（ない）でご評価（ひょうか）いただければ、と考（かんが）えています。

▶ 追问下限时：九百万円台（きゅうひゃくまんえんだい）から、を目安（めやす）に。（蓝色补充框，用 ▶）

▷ 中文策略：锚点用真实身价，绝不主动往下砍。

## 攻略メモ

**① 策略小标题用整行加粗**

正文段落直接写，会变成普通段落。列表用 `- `。

---

**要点**：
- `##` 每个成一个 section + 顶部导航 chip
- `【あなた】` 绿框、`【面接官】` 紫框、`▷` 黄框(中文)、`▶` 蓝框、`>` 金框
- 所有日语难读词 `漢字（かな）` → 自动 ruby
- 数字务必注音：1000万＝いっせんまん、12年間＝じゅうにねんかん
