# 本机面谈模块

入口 `/consultation`，有独立的老师阅读外壳。侧栏整页跳转以清除个人看板状态。`/api/consultation` 只在开发模式和 loopback Host 上开放；生产返回 404。没有分享、导出、邮件或发布操作。

## 正本与分层

- 私有 vault `20_求職/_面談相談/現在の相談.md`：`type: career-consultation`、`ai_author`；`consultation:start/end` 标记内的 JSON 保存本次背景、最多 3 主 2 备的材料、来源和隐私规则。
- 私有 vault `20_求職/_面談相談/相談メモ.md`：`type: career-consultation-record`、`layer: human-feedback`；`consultation-record:start/end` 内按保存时间追记草稿快照。`confirmed` 只表示本人已与老师确认该摘要，不能升级为老师逐语发言。
- 逐字稿、整理稿、本人批注、AI 复盘不改写。老师反馈不进入原有 `agree/disagree/context`，不自动转待办、日程、求职状态或重新分析。

## 材料契约

运行时契约在 `lib/consultation.ts`。`sources` 以完整 vault 路径读取原稿、整理稿、批注，三个 SHA-256 都是 UTF-8 文件全文（包括 frontmatter）。原稿或批注变化即拒绝投影，防止旧行号遮错个人信息。必须重新核对后更新版本，不可只自动换哈希。

`bodyRange`、`hiddenRanges` 和各材料的 `rawRange` 是原文件的一基闭区间行号。`blocks` 是整理稿的 qNN，保持 sNN 顺序。原始转写不按「マイク」猜话者，部分原文跨录音段时用原文件的连续行核对。准备材料时先读完整来源，再选区间、核前后文及批注；不把整理稿 `gen ?? sei` 拼接后当逐字原稿。

公司名默认用企业字母代号；`aliases` 覆盖原稿的不同写法。`privateTerms` 保存经全文核对的联系人等词形，`hiddenRanges` 隐藏无关个人信息段。通用过滤补充遮蔽邮箱、电话、URL、wiki 链接。展示真公司名不解除其余遮蔽。人工筛选和版本校验是必要条件，正则不能替代隐私核查。

背景、岗位和事后说明必须有来源。日文优先，中文辅助只切换本页。AI 评论默认折叠、标作者和日期，不显示评分或录用概率。转写不明、裁定未完成及材料局限必须可见。

## 保存与导航

编辑中的草稿留在当前页面内存；切换片段、正文语言和全文阅读不会卸载会话。片段由 `?part=` 定位，滚动位置按片段保留。离开提醒、刷新前提醒保护未保存内容；浏览器崩溃前未保存的文字不可恢复。

手动保存到 vault，接口按资料与记录内容哈希做版本检查，并串行处理同一记录的写入。重复保存去重、历史快照保留，PUT 后读取正文完全一致才报告成功。另一进程直接修改 vault 仍可能发生竞态，出现冲突时保留本页输入，人工合并后重读。

## 验证

`node --test tests/consultation.test.mjs` 覆盖隐私、话者裁定、缺失引用、源稿变化、草稿校验、写入回读、重复保存、并发冲突及独立首屏。再运行 `npm test`。实际浏览器验收在 main 工作区的 `localhost:3000`，只验收桌面；私有原稿和截图不能提交到公开仓库。
