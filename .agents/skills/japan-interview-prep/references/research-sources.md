# 调研信源清单（日本求职特化）

按本轮岗位判断选择信源，优先完整一手资料。研究结果进入 v2 的「纵览与建议」「研究资料」；旧版专用输出见 [legacy-prep.md](legacy-prep.md)。

## 一、公司调研

### 官网（第一手·最重要）
使用当前环境可用的网页读取工具；正文为空壳或不完整时，再用浏览器读取渲染后的正文。公开全文不要求登录。
- 先看首页导航结构（`/about-us`、`/recruit`、`/service`、`/blog`、`/news`），路径常和猜的不一样（试 `/info` 404 但 `/about-us` 有）。
- **会社案内/about-us**：役员职责、事业领域、企业理念、组织图。只记录与岗位判断有关的公开事实。
- **採用/recruit**：文化、求める人材、社内風景、员工访谈。
- **服务/产品页**（有时是独立子域名）：了解业务提供什么、解决谁的问题，寻找能支撑志望动机与贡献判断的具体事实。
- **blog/技术ページ**：方法论、技术观点——可能就是某位面接官写的（查作者！）。
- 引用具体公告、案例、IR 数字时保存**直接页面 URL**，不要用官网首页代替。每条 URL 同时记录阅读日期、已读范围、“支持哪项结论”以及岗位／团队／时点边界。试验、个别案例和生产实践分开写。

### 口碑站（员工评价·注意样本量）
- **OpenWork**（openwork.jp）：评分+员工口碑，详细内容常需登录会员。
- **ライトハウス/en-hyouban**（en-hyouban.com）：评分+口碑。注意 URL 里的公司 ID 要对准。
- **転職会議 / jobtalk**：口碑。
- 样本量、评论日期、岗位和地区会影响参考价值。样本不足就明示；不能从零星评论或“没差评”推出公司的普遍状况。口碑是待核实的观察，不代替公司一手事实。

### 招聘平台/媒体（会社概要·SSR 好抓）
- **Green**（green-japan.com）：常有**社长/役员访谈**（创业故事、理念、组织），信息量大。
- **マイナビ転職 / doda / type / Indeed**：会社概要、待遇、募集要项。
- **仕事博士 / readycrew 等聚合媒体**：二手整理，可补充。

🔴 求人搜索、求人详情、站内消息和个人账号操作用本人已登录的 Chrome 会话查看。游客视角会漏掉会员限定求人；
登录会话不可用时停止该部分并请本人接通，不能退回匿名读取后下“没有”的结论。
公开博客、员工访谈、公司／产品介绍等若未登录也能取得完整原文，可直接匿名读取；包括招聘站点托管的公开文章。
无需为这类全文要求登录；只取得摘要、节选或登录墙时明示，不作为已读全文。

### ⚠️ 同名公司区分
搜索时常撞到同名别家（如「ＡＢＣ ＪＡＰＡＮ株式会社」vs 别家的「株式会社abc」vs「ABCジャパン」）。认准官网域名和公司全名，口碑站认准公司 ID。搞混会给出错误情报。

## 二、面接官调研（知己知彼·高价值）

拿到已确认出席者的姓名／职位后，查与本轮有关的公开背景；不要把连络人当作确定面接官。
- **LinkedIn**：职位、经历、学历、关注话题、发布内容。搜 `"面接官全名(罗马字)" 公司名`。个人资料全文常需登录；搜索摘要只用于定位可核验原文。公开完整正文可匿名读取；未取得正文就标为未核验，不据摘要判断当前职务或面接官画像。登录查看个人资料可能留下访客记录，应考虑本次调研是否确有必要。
- **登壇/セミナー/イベント**：技术会议、公司 event 页——反映其技术关注点。
- **技术博客/note/Qiita/Zenn**：本人写的技术文章 = 最直接的关注点和价值观。
- **公司メンバー紹介/组织图**：职位、部门。

公开文章可帮助理解其工作职责与业务关注，但学历、职位或单篇文章不能证明其面试偏好。只有确与本轮岗位有关时，才据此调整证据深度或准备一个具体追问；推断明确标注，不写心理画像。

## 三、把调研落成情报的产物

边查边留存所有实际采用的直接 URL 及其支持的事实，最终写入「研究资料」。研究深度体现在判断与证据，不用额外速查表、词汇表或 HTML 增加产物数量。

1. **纵览与建议**：围绕公司怎样提供价值、当前岗位做什么、本人证据能支持哪项贡献、机会与待确认条件展开。技术细节和已核实的面接官职责融入相关判断；不写公司沿革流水账。
2. **志望動機依据**：选一项真正适用于本公司及岗位的事实，附官方直接页面，并另回链一条本人经历。公司案例不能证明候选人也具备相同能力。
3. **研究资料**：每项一个 H3 与完整直接链接，写“读到了什么／与你的关系／建议关注什么”，附阅读日期及范围。后轮新增实际采用的新来源或已变化的用途，沿用历史可用来源；重点三条从截至本轮的累计资料中选，累计不足三条不凑数，历史已有标记不回写。页面累计与重点显示规则以 [SKILL.md](../SKILL.md) 为准。
4. **逆質問**：把研究后仍未解决的岗位问题变成可判断的提问；不再问邀请或前轮已回答的事实。已有答案但需更具体时，说明待补的例子或适用范围。
5. **company 卷宗回流**：把商业模式、长期业务方向、稳定的公开职责和官方链接写回 `_<会社>.md`；前轮现场获知的公司事实回链具体整理稿 `#qNN`，不只引用 AI 复盘。面接官战术、当轮问答、日期和会议入口只留本轮准备笔记。

任何“语言环境适合”“支持在留手续”等结论都要有与当前岗位相关的明确证据；未说明就是待确认，不能由员工国籍或海外业务推断。
