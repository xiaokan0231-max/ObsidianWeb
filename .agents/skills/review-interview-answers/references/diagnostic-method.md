# 证据驱动的复盘方法（2026-10 v3）

旧法偏重孤立子问、语法和风险标签，没稳定检查时间、对象、数量/类型与个人/团队责任；容易把错位归为误听、把AI训练稿错误归给本人、把澄清和诚实边界判成缺陷。零扣分默认100和五维平均又把关键问题淡化。本版以连续问答为单位，五维用于有据评分、证据归类与未检验边界，七个视角按真实问题触发，不强填缺陷。

## 先确认是谁的什么文字

导读末说明来源、实际覆盖、缺段、原音可用性与裁定状态。分析底稿分层：

| 层 | 可作证据 | 不可作证据 |
|---|---|---|
| 原问答/ASR逐字稿 | 同清洗稿、裁定互核后的问题和答题内容 | 无原音不推发音、语速、口音；乱码不等于能力差 |
| 整理稿`正/原` | `正`供可读分析，`原`检查是否补写，q/s冻结 | 修复文本、翻译、概述、注解不证明本人现场说过 |
| 本人批注`我`与裁定 | 误听自述、话者、事实边界和补充经历 | 事后会答不等于现场已答；AI代写的`我`不自动是人工事实 |
| AI的`AI`、旧复盘、准备/改善稿 | 待核查训练线索 | 不当本人原话/能力证据，不把AI写错算用户失误 |
| 原JD/原通知/公司反馈 | 本岗位要求、真实推进和明确反馈 | 不推广全部日本企业，不用套话/结果倒推个人拒因 |

区分人工确认、本人授权自动整理、仅AI自裁；“answered/applied”不等于本人逐句听音确认。影响结论的未决话者/缺问句禁止扣分。已获授权自动整理的无关姓名/寒暄疑点可保留并排除，不要求重新停全场。未经授权且门槛未满足，只做有边界审计，不生成完整持久化质量报告。

## 连续问答是最小诊断单位

先不看旧分，读全场。每q：问的对象/时段/维度/子问 → 实际回答 → 前后追问/复述/改口是否补齐 → 判断证据与原因证据 → 具体改法。跨q追踪同一事件；JSON块内s仍只能引用本q，跨块在文字列q并在对应块留证据。

先按原问句定义最小充分回答，不从AI概/注或准备模板扩张askedPoints。问转职契机时，实际过渡安排可以是合理契机，不强求未被问的该公司独特吸引力；回答已交付实质含义时，不因缺显式yes/no或理想结构直接判major。区分相关信息已交付但范围未说全（通常moderate或无扣分机会）与整个维度被另一题替代。扣分前主动找至少一个支持“已足够回答”的合理解释，若不能说明它为何不足，保留优化而不扣。

先判“内容偏移可确认”，再判原因。答偏还可能来自组织、选择性回答、缺录或话者错配，不能等同没听懂。本人明确聴解批注可确认误听；无依据写原因未知，`comprehension=partial`只表示未充分对齐，不能解释成听力差。`likely_missed`需可靠误听依据。不知道、没展示个人经历、未匹配岗位都不是误听。

追问可能是在要求补缺，也可能是在认可一般回答后转为新子问。按原话逐轮追踪要求是否变化；对方已经复述一个可用回答，再问不同具体角度且本人答到时，不因旧题缺理想故事自动扣分。礼貌认可不能单独证明充分，但换问也不能单独证明失败；有歧义或缺录则留机会/限制。

写清恢复时间：初答偏离，追问后补齐；不能因末句正确消掉初始事件，也不能把已修复说成整场未答。成功澄清且无残余损失不扣分。原问未录/主语归属争议不诊断错位。

## 七个观察视角，按现场触发

| 视角与真实失效形状 | 如何核查及保留正例 | 五维归属 |
|---|---|---|
| 听题/意图：过去→未来、类型→数量、主语反转 | 保留时间/对象/维度，核后续修复；成功请简化问法为正例 | 有误听依据归理解，否则未交付归覆盖 |
| 充分性/证据：求episode只讲原则、ROI答管线共性 | 问要结论/判断/事件？一个本人动作胜过术语清单；不要求每题STAR/数字 | 覆盖；独立泛化主张归可信度 |
| 个人贡献/一致性：个人程度答团队分工、核心和整体人数混淆 | 区分本人/团队/模拟/生产/PoC/计划；数字单位基线；诚实边界为正例 | 可信度 |
| 匹配/资深度：平台经验当PdM或客户PM证明、非工程师标签遮住hands-on | 以本岗位真实要求看判断取舍、交付和职责；未问选型不造缺口 | 风险或独立证据不足 |
| 动机/转职：有真实原因但未交付下一步选择逻辑 | 核时间轴与本人真实意愿；后续通过保留，追问不自动为失败 | 覆盖或风险，唯一事件归属 |
| 日语/语用：含义反转、范围责任变味、自我否定标签 | 确认学習者才批评；纯语法留一层，不二次扣；不鼓励隐藏真实边界 | 含义归覆盖，提取成本归直接性，标签归风险 |
| 追问/修正：继续答旧题、修复后仍被旧标签判错 | 看换问是否接住、是否确认后回到本题；成功修复留证据和可复用句 | 按残余损失归原事件 |

岗位匹配按任务与责任评估，不按历史技术栈同名与否固定职业范围。分别说明已证实的迁移基础、尚未掌握或未展示的知识/实务、学习意愿、企业支持与适应时间、入职即须独立承担的责任。愿意学不是已掌握；没有同名经历也不等于无法学或必须继续原领域。先提出可验证的迁移路径和需要核实的岗位条件，再判断缺口；当前本人补充的能力只作当前建议事实，不回写历史已答。

未触发视角是“未检验”，不是“优秀”。复述、具体赞赏、轮次推进、正式通过的证明范围分别说明，礼貌话不等于能力验证。

## 优先级：重要且改得动

严重度看核心信息是否交付、是否阻断本题判断、是否恢复；行动排序看证据可信度、实际影响、跨场复现、可改善程度与成本，以文字解释，不编收益公式。

导读开头两三段先给至多三项高价值行动，每项含q/s短摘原问答、缺失信息、严重度与原因置信度、下一次第一句/具体动作、复测方式。未知问法首次录答和听者复述优于背过后正确。同机制归并，但独有岗位要求留在详情。没有严重问题就说没有，不凑三项。

年龄、无日本经历、市场和手续限制单列背景，不占训练优先位。关键错位/事实边界/核心未交付早于流利和术语赞赏。至少保留一个真实强答或成功修复，解释为何有效/适用边界；资料没有则明示。

建议须可执行，例如随机换过去/将来问法，第一句答被问时段；听者复述本人动作与结果范围；随机两轮追问保持口径。改答只用确认事实，仅结构可提供时用空槽提示，不把空槽伪装成经历。不要只说多练日语/具体一点/加强逻辑。

## 行为验证与历史重评

改方法后至少三场完整问答和一场未提示问题的留出样本，包含强答和成功澄清。独立评估者只读指定版本和原问答/人工资料，不读审计答案、目标q、旧报告或他人判断。前后对照独立存放，同输入记录版本/来源哈希/实际覆盖/漏检/误报/原因捏造/改法可执行性；结构测试不能替代。

全量重评按完整路径、实际场次去重，准备/初稿/重复不算场次。缺录/回忆-only只做有边界分析；可靠原问答片段可评分局部，记忆重构不评分现场措辞，不补造整场分。新报告另存版本日期、保留旧输出，先样本后批量。历史回流只提候选建议，不自动批量改事实层。


## 默认显示反例验收

有据评分与关键改进同时可见，空账本不推出100。验收覆盖重大未恢复加其他维正证的50/60门槛、有限资料无整体分但可靠局部分、窄问充分无需STAR、成功澄清零扣、部分恢复减残余影响和正面强答加分。展示具体算式和覆盖，旧数字只标历史不同口径，不作能力涨跌。
