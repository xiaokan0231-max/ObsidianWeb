# 面谈资料阅读与交流

入口 `/consultation` 使用独立老师阅读界面。本机从 Vault 读取资料，线上只读取已发布快照；线上页面、资料接口和 DOCX 下载均受站点密码门禁保护。POST 不写入资料，老师交流通过独立鉴权的 R2 信箱进行。

## 阅读与来源

`GET /api/consultation` 返回公司及场次目录，`?session=` 返回选定场次。页面区分原始转写、可读整理稿、面试总结和记忆重构，保留来源说明；公司、场次、筛选、阅读形式和问题定位保存在 URL 中。缺少材料返回明确错误，不把连接失败显示成空目录。

Vault 是资料正本。读取和导出不会改变原稿、人工批注、AI 复盘、选考状态或日历。发布范围沿用 `publish: false` 和发布快照规则，不能为了修复页面重新导出未获准公开的本地资料。

## 导出

`GET /api/consultation/export?session=…&view=raw|readable` 下载选定场次的 DOCX；`?format=companies` 下载公司目录。导出名称及内容保留资料类型，不能把总结或记忆重构标作原始逐字稿。缺少对应原稿时返回 404，生成失败返回可重试错误。下载和接口响应均使用私有、不持久缓存策略。

## 留言与定位

老师和本人使用独立信箱身份。列表读取分页摘要，打开线程后才读取完整正文和完整引用。引用定位核对资料版本、范围及完整引用；摘要中截短的文字不能作为原文一致性证据。留言、引用、访问码和管理凭据不进入公开源码、Vault 发布快照、SQL 查询索引或自动 AI 输入。

写入、已读记录、未读轮询及故障恢复见 [老师交流信箱](feedback.md)。留言失败保留草稿与原操作 ID，允许重试；页面不得把新到达而未显示的回复标成已读。

## 验证

运行咨询目录、阅读入口、导出和留言相关测试，再执行 `npm test`。实际浏览器验收使用 main 工作区的 `http://localhost:3000`，只验收桌面。验证直接进入、筛选、场次切换、阅读定位、按需留言详情和 DOCX；私有原稿及截图不提交到公开仓库。
