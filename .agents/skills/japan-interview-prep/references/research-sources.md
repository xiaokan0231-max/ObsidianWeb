# 调研信源清单（日本求职特化）

面接准备的质量取决于调研深度。以下是这次会话验证有效的信源，按目标分类。多信源交叉，别只看一处。

## 一、公司调研

### 官网（第一手·最重要）
公司官网常是 JS 渲染的 SPA——`WebFetch` 经常抓不到内容（拿到空壳或 SPA shell）。**用浏览器工具（用户已登录的 Chrome）访问渲染后的页面**，或 `get_page_text`。
- 先看首页导航结构（`/about-us`、`/recruit`、`/service`、`/blog`、`/news`），路径常和猜的不一样（试 `/info` 404 但 `/about-us` 有）。
- **会社案内/about-us**：役员构成（判断创始人国籍/背景）、事业领域、沿革、企业理念、组织图。
- **採用/recruit**：文化、求める人材、社内風景、员工访谈。
- **服务/产品页**（有时是独立子域名，如 `service.公司.co.jp`）：自社产品的技术细节——这是技术拆解的金矿，也是志望动机"读过功课"的证据来源。
- **blog/技术ページ**：方法论、技术观点——可能就是某位面接官写的（查作者！）。
- 引用具体公告、案例、IR 数字时保存**直接页面 URL**，不要用官网首页代替。每条 URL 同时记录“支持哪项结论”。

### 口碑站（员工评价·注意样本量）
- **OpenWork**（openwork.jp）：评分+员工口碑，详细内容常需登录会员。
- **ライトハウス/en-hyouban**（en-hyouban.com）：评分+口碑。注意 URL 里的公司 ID 要对准。
- **転職会議 / jobtalk**：口碑。
- ⚠️ **成立年数短、人数少的公司口碑样本天然极少**（3年67人可能只有个位数评论）。别过度解读零星评论，也别因为"没差评"就以为很好——如实告诉用户样本不足，转而用多信源交叉出的"实态画像"（更可靠）。

### 招聘平台/媒体（会社概要·SSR 好抓）
- **Green**（green-japan.com）：常有**社长/役员访谈**（创业故事、理念、组织），信息量大。
- **マイナビ転職 / doda / type / Indeed**：会社概要、待遇、募集要项。
- **仕事博士 / readycrew 等聚合媒体**：二手整理，可补充。

🔴 RA / Green / Indeed 等**所有求人站点**一律用本人已登录的 Chrome 会话查看。游客视角会漏掉会员限定求人；
登录会话不可用时停止并请本人接通，不能退回匿名 WebFetch 后下“没有”的结论。

### ⚠️ 同名公司区分
搜索时常撞到同名别家（如「MCT JAPAN株式会社」vs 大阪的设计公司「株式会社mct」vs「MTCジャパン」）。认准官网域名和公司全名，口碑站认准公司 ID。搞混会给出错误情报。

## 二、面接官调研（知己知彼·高价值）

拿到面接官姓名/职位后，尽量查其公开背景——这次会话证明这是"降维打击级"的准备。
- **LinkedIn**：职位、经历、学历、关注话题、发布内容。搜 `"面接官全名(罗马字)" 公司名`。⚠️ LinkedIn profile 全文常需登录；搜索引擎摘要里往往已有关键信息（现职、自述）。**提醒用户：用自己账号看会给对方留"谁看了你的主页"记录**，可能微妙——建议匿名浏览或让 AI 从公开摘要提取。
- **登壇/セミナー/イベント**：技术会议、公司 event 页——反映其技术关注点。
- **技术博客/note/Qiita/Zenn**：本人写的技术文章 = 最直接的关注点和价值观。
- **公司メンバー紹介/组织图**：职位、部门。

**关键判断**：面接官的背景直接改写打法——
- 面接官是某官网方法论/产品的**作者本人** → 候选人的共鸣变成"内行对作者的致敬"，但必须落到具体、不能空夸（作者验真）。
- 面接官有 **MBA/经营背景 + 关注团队管理** → 候选人的管理经验要和技术并排亮，他吃"技术也懂+能带团队"这套。
- 面接官关注 **某技术方向**（low-code、某框架）→ 对应准备。

## 三、把调研落成情报的产物

⚠️ **调研过程中边查边留存每一条用过的链接**（URL+一句"这页有什么"）——最终要落成文档的「会社研究リンク集」一节，别等写文档时回忆不起来。

调研完，为文档产出这几块（都进 HTML）：
1. **会社速查表**：设立/人数/资本金/营收/理念/事业/待遇/地点。
2. **役员/面接官画像**：谁、背景、看什么、怎么打、雷区。
3. **技术拆解**：自社产品的技术路线 + 候选人能贡献的点（对口证据）。
4. **文化/追い風**：对该候选人特别有利的点（签证友好、语言环境、方向对口等）。
5. **面接官情报框**（若查到）：姓名/职位/背景/⭐战略提示。
6. **会社研究リンク集**：所有用过的链接按用途分类（求人・採用／公式・プロダクト／CEO・思想／資金調達・企業DB／ニュース・提携／其他求人媒体），
   每链一句注释，使用可点击的直接页面，标出**恰好3条**“面談前最終復習”。同时从调研材料里顺手提取：
   该公司**頻出技術用語**（进単語帳B节）和**公司豆知識**（社名词源/产品命名梗，雑談用）。
7. **company 卷宗回流**：把商业模式、长期业务方向、稳定的面接官公开履历、官方链接写回 `_<会社>.md`；前轮面接中首次知道的公司事实必须回链具体整理稿 `#qNN`，不能只引用 AI 复盘。面接官打法、当轮问答和会议链接只留在本轮准备笔记。
